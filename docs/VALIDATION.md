# 0.5.0 本地验证

已在 Windows 开发环境执行：

- 20 组单元测试：原有图片/PDF处理、预览、原文件保护、单实例消息，以及原文字替换、字体/颜色修改、中文字体、失败回滚、图片移动替换、标注、多页管理和撤销/重做。
- 新工作区交互测试：分类导航、点击已有文字、修改内容和字体、查找跳页、页面网格、保存、图片/PDF 压缩对比与导出字节一致性；检查 1120×760 与 1360×900 布局截图。
- 安装升级实测：0.3→0.4→0.5 复用安装目录和应用标识，验证快捷方式、启动项、右键菜单、安装后 EXE 启动及卸载；测试结束后恢复原用户配置。
- 图片拼贴界面、预览与导出一致性、系统托盘与单实例生命周期回归通过。
- 保存后重新读取验证：旧文字消失、新文字和字体属性保留，邻近文字与页面背景不变，原文件校验值不变。

测试使用自动生成的示例 PDF，未取得用户截图对应的源 PDF，不能据此保证每种实际文档都能编辑。

尚未在独立 Windows 10、高 DPI、多显示器或用户的 GitHub Actions 环境验证。本版本没有商业数字签名。
