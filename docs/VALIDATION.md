# 0.4.0 本地验证

已在 Windows 11 x64 开发环境执行：

- 14 组单元测试，覆盖图片/PDF 处理、原文件保护、拼图预览与导出一致性、单实例选举、消息投递和重启，以及 PDF 编辑、撤销、保存与失败回滚。
- PDF 界面测试：翻页预览、从当前页进入编辑、添加文字、排序和撤销、另存；检查 1120×760 与 1360×900 窗口截图，确认原文件未改变。
- 桌面生命周期测试：托盘可见、关闭收起、恢复、同一窗口接收多文件、任务中延迟导入、彻底退出。
- 安装包升级实测：先安装 0.3.0，再升级 0.4.0，确认复用安装路径和应用标识、Toolbox 名称及版本、旧快捷方式清理、右键/发送到/启动项迁移，以及安装后的 EXE 启动。
- 升级后卸载实测：应用列表、程序文件、右键菜单清理。测试后恢复先前的菜单、快捷方式和启动项配置。
- 源码包按文件白名单生成，不含测试素材、处理报告、虚拟环境、构建缓存或本机路径。

尚未在独立 Windows 10、高 DPI、多显示器或用户的 GitHub Actions 环境验证。本版本没有商业数字签名。
