# Toolbox 0.4.0

- 软件统一更名为 Toolbox，沿用原应用标识进行升级。
- 新增 PDF 翻页预览、缩略图、缩放和编辑入口。
- PDF 页面拖动排序、旋转、删除、插入 PDF/图片页、撤销。
- 在页面上框选区域添加中文文字、图片和视觉遮盖块，另存 PDF。
- 移除“完全本地”“原文件保留”等常驻提示，保留必要操作提示。
- 遮盖块不等于脱敏；暂不提供原有段落直接改写或自动重排版。

安装前请退出旧版托盘程序。应用名称、快捷方式、右键显示名称和启动项在升级时迁移。

## 延续功能

- 真正的 Windows 安装程序：安装目录、桌面/开始菜单快捷方式、应用列表与卸载支持。
- 关闭窗口收起到系统托盘，可通过托盘打开或彻底退出。
- 开机启动可选，默认关闭；所有处理在本地完成，无需账号和网络。
- 同一 Windows 用户只运行一个主窗口，后续启动与右键导入会唤起现有窗口。
- 正在处理时，新导入文件暂存，完成后自动加入素材列表。
- 安装时可注册右键菜单和“发送到”入口；可多选文件后通过“发送到 → Toolbox”导入。
- 保留图片 / PDF 批处理与拼图预览。

Windows 11 的传统右键入口位于“显示更多选项”。本版本安装包未进行商业代码签名，首次运行可能出现 Windows 提示。智能抠图尚未加入。

安装包中附带本项目完整源码、AGPL-3.0 许可证与第三方许可。卸载不会删除用户原文件和已导出的文件。
