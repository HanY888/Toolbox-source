# 拾光工具箱 0.3.0

- 真正的 Windows 安装程序：安装目录、桌面/开始菜单快捷方式、应用列表与卸载支持。
- 关闭窗口收起到系统托盘，可通过托盘打开或彻底退出。
- 开机启动可选，默认关闭；所有处理在本地完成，无需账号和网络。
- 同一 Windows 用户只运行一个主窗口，后续启动与右键导入会唤起现有窗口。
- 正在处理时，新导入文件暂存，完成后自动加入素材列表。
- 安装时可注册右键菜单和“发送到”入口；可多选文件后通过“发送到 → 拾光工具箱”导入。
- 保留图片 / PDF 批处理与拼图预览。

Windows 11 的传统右键入口位于“显示更多选项”。本版本安装包未进行商业代码签名，首次运行可能出现 Windows 提示。智能抠图、PDF 页面预览尚未加入。

安装包中附带本项目完整源码、AGPL-3.0 许可证与第三方许可。卸载不会删除用户原文件和已导出的文件。
