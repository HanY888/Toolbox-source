# Toolbox 0.5.0

- 重构工作区：浅灰/白色与蓝色强调，首页工具卡片，按 PDF / 图片 / 批处理分类导航。
- 原有 PDF 文字可点选后修改内容、字体、字号、颜色与位置；替换底层文字，保留周围图形。新增重做。
- 原有图片支持移动、缩放、替换和删除；共享图片资源暂不支持单独编辑。
- 全文查找与结果定位；高亮、下划线、删除线、便签、矩形和箭头标注。
- 页面管理网格，多选旋转/删除/提取，拖动排序，跨文件插入页面。
- 图片与 PDF 压缩对比：实际生成结果，显示体积变化、同步查看局部、直接导出。
- 清理重复入口，编辑模式隐藏输出目录，右侧显示选中对象属性，任务期间才显示进度条。

文字编辑以单行片段为单位；扫描件、文字转曲、旋转/重叠文字和段落自动重排尚不支持。部分原字体可能无法复用，可选已安装字体。OCR 等第二阶段功能尚未加入。

安装前请从托盘退出旧版程序，再运行新版安装包。延续原应用标识、安装目录、右键菜单和托盘支持。
